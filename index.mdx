The Bank Management System is a Java console application that demonstrates a clean, layered architecture for core banking operations. It provides a `BankService` interface backed by an in-memory repository layer, supporting account creation, fund management, and transaction tracking — all without any external dependencies.

## Get up and running

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/VaibhavDongre/Bank-Management-System-using-Java.git
    cd Bank-Management-System-using-Java
    ```
  </Step>
  <Step title="Compile all sources">
    ```bash
    find src -name "*.java" | xargs javac -d out
    ```
  </Step>
  <Step title="Run the application">
    ```bash
    java -cp out app.Main
    ```
  </Step>
  <Step title="Interact with the menu">
    Follow the console menu to open accounts, deposit funds, transfer money, and view statements.
  </Step>
</Steps>

<Note>
  All data is stored in memory. Restarting the application resets all accounts and transactions.
</Note>
