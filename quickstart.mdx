This guide walks you through everything needed to get the Bank Management System running on your machine. By the end you will have compiled the project from source, launched the console menu, opened a bank account for a new customer, deposited funds, and retrieved a formatted transaction statement — all without touching a database or installing any build tool beyond the JDK.

<Warning>
  Java 17 or higher is required. `Main.java` uses text blocks (the multi-line `"""..."""` syntax for the menu) and arrow-style `switch` expressions, both of which were finalised in Java 17. Earlier versions will fail to compile.
</Warning>

## Steps

<Steps>
  <Step title="Clone the repository">
    Download the source code and enter the project directory:

    ```bash
    git clone https://github.com/VaibhavDongre/Bank-Management-System-using-Java.git && cd Bank-Management-System-using-Java
    ```
  </Step>

  <Step title="Compile all sources">
    Create the output directory, then compile every `.java` file under `src/` in one `javac` invocation:

    ```bash
    mkdir -p out
    find src -name "*.java" -exec javac -d out {} +
    ```

    All compiled `.class` files will be written to the `out/` directory, preserving the package hierarchy.
  </Step>

  <Step title="Run the application">
    Launch the application by pointing the classpath at `out/` and specifying the fully-qualified main class:

    ```bash
    java -cp out app.Main
    ```
  </Step>

  <Step title="Interact with the menu">
    After startup the console prints a welcome message followed by the main menu. Enter the number that corresponds to the operation you want to perform:

    ```text
    Welcome to Console Bank
        1) Open Account
        2) Deposit
        3) Withdraw
        4) Transfer
        5) Account Statement
        6) List Accounts
        7) Search Accounts by Customer Name
        0) Exit
    ```

    Type your choice and press **Enter**. The application loops back to this menu after each operation until you enter `0` to exit.
  </Step>
</Steps>

## Your First Session

The walkthrough below shows a realistic sequence of interactions immediately after starting the app. Prompts printed by the application are shown without a prefix; your input lines are preceded by `>`.

```text
Welcome to Console Bank
    1) Open Account
    2) Deposit
    3) Withdraw
    4) Transfer
    5) Account Statement
    6) List Accounts
    7) Search Accounts by Customer Name
    0) Exit

CHOOSE: > 1
CHOICE: 1
Customer name: 
> Alice Smith
Customer email: 
> alice@example.com
Account Type (SAVINGS/CURRENT): 
> SAVINGS
Initial deposit (optional, bank for 0): 
> 1000
Account opened: AC000001

CHOOSE: > 2
CHOICE: 2
Account number: 
> AC000001
Amount: 
> 500
Deposited

CHOOSE: > 5
CHOICE: 5
Account Number: 
> AC000001
2024-06-01T10:15:32.104 | DEPOSIT | 1000.0 | Initial Deposit
2024-06-01T10:16:44.821 | DEPOSIT | 500.0 | Deposit

CHOOSE: > 0
CHOICE: 0
```

**What happened:**
1. Option `1` collected the customer's name, email, account type, and optional initial deposit. The service created a `Customer` record (UUID-keyed), then an `Account` record numbered `AC000001`, and recorded a `DEPOSIT` transaction for the initial 1 000.
2. Option `2` added a further 500 to `AC000001` and appended a second `DEPOSIT` transaction.
3. Option `5` fetched all transactions for `AC000001`, sorted them by timestamp, and printed each row as `timestamp | type | amount | note`.
4. Option `0` set the `running` flag to `false`, exiting the `while` loop and terminating the JVM.

<Tip>
  Use option `7` (Search Accounts by Customer Name) to find an account when you know the customer's name but not the account number. The search is case-insensitive and matches any substring — entering `ali` will match `Alice Smith`.
</Tip>
